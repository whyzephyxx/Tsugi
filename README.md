# Tsugi (次)

**Never Miss What's Next.**

Initial project scaffold for the Tsugi responsive web app.

## Stack

- Next.js
- React
- TypeScript
- App Router
- ESLint

## Development

```bash
npm install
npm run dev
```

Then open the local URL shown by Next.js.

## Production build

```bash
npm run build
npm start
```

## Scope of this scaffold

This is intentionally only the project foundation. It does not yet include:

- Supabase
- Resend
- Authentication
- Database schema
- API integrations
- Final UI/UX
- Community functionality
- Library/tracking functionality
- Secrets or environment variables

Tsugi targets a $0/month MVP using free tiers/free services wherever possible. Any service that may incur charges must be explicitly reviewed before use.
